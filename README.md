# 훈맹정색 訓盲正色 — 천지인 칼라 패턴 짝 맞추기

> 훈맹정음이 손끝으로 읽는 글자라면, 훈맹정색은 손끝으로 읽는 색입니다.

『촉각 칼라 북 — 시각장애인들의 칼라 이해를 돕는 촉각 명화 감상』(성균관대학교 휴먼ICT융합 연구센터)에 실린 **천지인 칼라 패턴**을 익히고, 색과 무늬의 짝을 맞추는 웹 게임입니다. 휴대폰·태블릿·PC 브라우저에서 설치 없이 바로 쓸 수 있습니다. **TalkBack·VoiceOver 같은 화면 읽기 프로그램을 써도 되고, 쓰지 않아도** 앞을 보지 않고 끝까지 할 수 있도록 만들었습니다.

---

## 천지인 칼라 패턴

| 색 | 천지인 | 무늬 | 연상 |
|---|---|---|---|
| 빨강 | 하늘 | 둥근 점 | 수평선에서 솟는 해 |
| 노랑 | 사람 | 사선(빗금) | 땅 위로 내리쬐는 빛 |
| 파랑 | 땅 | 물결 | 서쪽으로 지며 식어가는 해 |
| 2차색 (주황·초록·남색·보라) | — | 두 무늬를 합친 모양 | 예: 초록 = 파랑의 곡선 + 노랑의 직선 = 나뭇잎 |
| 흰색 · 회색 · 검정 | 무채색 | 작은 점 다섯 개 · 점 두 개 · 무늬 없음 | 빛 · 잿빛 · 어둠 |

- **명도:** 점·선의 **개수가 많을수록** 밝은 색입니다.
- **채도:** 점·선이 **굵을수록** 선명한 색입니다.
- 한 색마다 순색(S)·밝은 색(L)·탁한 색(M)·어두운 색(D) 네 가지가 있습니다. 모두 합치면 **31가지**입니다.

---

## 구성

| 메뉴 | 내용 |
|---|---|
| **패턴 도감** | 31가지 무늬를 표로 봅니다. 무늬를 누르면 색 이름, 모양, 연상물을 들려줍니다. |
| **짝 맞추기 1~4단계** | 색을 보고 무늬를, 또는 무늬를 보고 색을 고릅니다. 한 단계는 8문제이고, 틀린 수에 따라 별을 1~3개 받습니다. 모든 단계가 처음부터 열려 있습니다. |
| &nbsp;&nbsp;1단계 하늘·사람·땅 | 빨강·노랑·파랑, 흰색·회색·검정 |
| &nbsp;&nbsp;2단계 섞인 색 | 주황·초록·남색·보라 |
| &nbsp;&nbsp;3단계 밝고 어둡게 | 같은 색의 순색·밝은·탁한·어두운 색 구별 |
| &nbsp;&nbsp;4단계 모두 모아 | 31가지 전체 |
| **카드 짝 맞추기** | 뒤집힌 카드 12장에서 색 카드와 무늬 카드의 짝 6쌍을 찾습니다. |
| **명화에 무늬 입히기** | 『촉각 칼라 북』 3장의 명화 다섯 점에 알맞은 무늬를 채웁니다. 틀리면 색 계열을 알려 주고, 같은 곳을 두 번 틀리면 정답을 알려 줍니다. 💡 자리 비추기와 📖 작품 이야기를 쓸 수 있습니다. |

**명화 다섯 점:** 고흐 「별이 빛나는 밤」, 피카소 「아비뇽의 처녀들」, 마티스 「춤」, 칼로 「원숭이와 함께한 자화상」, 고갱 「아레아레아, 기쁨」

## 접근성 — 보이지 않아도 쓰는 법

사용 방식은 처음 화면의 **사용 방식** 버튼과, 각 화면 위쪽의 🔊 / 👆 / 📱 버튼에서 고릅니다. 고른 방식은 기기에 저장됩니다.

### 🔊 기본
누르면 바로 실행되고, 앱이 음성(한국어 TTS)과 화면 아래 자막으로 안내합니다. 🗣 버튼으로 앱 음성을 켜고 끕니다. 자막은 음성을 꺼도 계속 나옵니다.

### 👆 음성 터치 — 화면 읽기 프로그램 없이
앱이 직접 읽어 주는 방식이며, TalkBack과 비슷하게 동작합니다.

| 동작 | 결과 |
|---|---|
| 한 번 누르기 | 그 항목의 이름을 읽어 줍니다. |
| 같은 것을 한 번 더 누르기 | 실행합니다. |
| 오른쪽 / 왼쪽으로 밀기 | 다음 / 이전 항목으로 옮겨 가며 읽어 줍니다. |
| 빈 곳을 빠르게 두 번 누르기 | 지금 고른 항목을 실행합니다. |
| 길게 누르기 | 지금 화면을 요약해 줍니다. |
| 명화 위에 손가락을 댄 채 움직이기 | 지나가는 자리를 짧은 진동과 함께 읽어 줍니다. 손을 떼고 같은 자리를 한 번 더 누르면 그 자리를 고릅니다. |

> **기본 방식에서 화면 아무 곳이나 1초 동안 길게 누르면** 음성 터치 방식이 바로 켜집니다. 버튼 위치를 몰라도 켤 수 있게 한 것입니다.

### 📱 화면 읽기 — TalkBack(안드로이드) · VoiceOver(아이폰)
- 앱 자체 음성을 꺼서 목소리가 겹치지 않습니다. 정답·오답 같은 알림은 화면 읽기 프로그램이 읽어 줍니다.
- 화면 읽기로 버튼을 두 번 눌러 실행하면 이를 알아채고 **이 방식으로 자동으로 바뀝니다.** 아이폰 VoiceOver에서는 자동으로 바뀌지 않을 수 있으니, 그때는 직접 고르세요.
- **문제 풀기:** 새 문제가 나오면 문제 카드로 초점이 옮겨 가서 전체 문장을 읽습니다(예: "8문제 중 1번째. 이 무늬는 어떤 색일까요?…"). 답을 고르면 보기에 "정답"·"고른 답, 틀림"이 붙습니다.
- **명화에 무늬 입히기:** 📋 **자리 목록**에서 "1번 자리, 가운데 위, 아주 넓은 곳, 빈 자리"처럼 들으며 자리를 고릅니다. 자리는 위에서 아래, 왼쪽에서 오른쪽 순서로 나옵니다.
- 완료·안내·사용 방식 창이 열리면 뒤 화면은 화면 읽기에서 가려집니다. 완료 창의 별은 "별 3개 중 2개"처럼 읽힙니다.

### 그 밖에
- 모든 버튼은 손가락으로 누르기 쉽도록 48px 이상으로 만들었습니다.
- 키보드로도 쓸 수 있습니다. `Tab`으로 이동하고, `Enter`·`Space`로 선택하고, `Esc`로 창을 닫습니다. 안내 창의 탭은 `←` `→`로 옮깁니다.
- 기기의 "동작 줄이기" 설정을 따릅니다.
- 진동을 지원하는 휴대폰에서는 정답과 오답을 진동으로도 알려 줍니다.

## 파일 구성

```
index.html                  ← 게임 전체 (무늬 그림 31개와 명화 영역 지도가 파일 안에 들어 있음)
paintings/
  vangogh-line.png          vangogh-pattern.png
  picasso-line.png          picasso-pattern.png
  matisse-line.png          matisse-pattern.png
  kahlo-line.png            kahlo-pattern.png
  gauguin-line.png          gauguin-pattern.png
README.md
```

`paintings` 폴더(그림 10개)는 **명화에 무늬 입히기**에만 쓰입니다. 폴더는 `index.html`과 같은 곳에 두어야 합니다.

## 실행 방법

- **파일로 열기:** `index.html`을 브라우저로 열면 됩니다. 명화도 파일로 연 상태에서 동작합니다.
- **웹에 올리기:** 폴더를 통째로 GitHub Pages나 일반 웹 서버에 올리면 됩니다. 따로 빌드하거나 설치할 것은 없습니다.
- **인터넷 연결:** 글꼴(Gowun Batang·Gowun Dodum)은 Google Fonts에서 받아 옵니다. 인터넷이 없으면 기기 기본 글꼴로 보입니다.
- **권장 브라우저:** 안드로이드 Chrome, 아이폰 Safari, PC의 Chrome·Edge·Safari 최신판. 앱 음성은 브라우저의 한국어 음성 합성(Web Speech API)을 씁니다. 한국어 음성이 없는 기기에서는 자막만 나옵니다.
